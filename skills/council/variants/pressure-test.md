# Variant — Pressure Test

**Bias:** Contrarian-heavy. Used when the user is too in love with their own idea and needs the steel-wool treatment.

## How this variant differs from default council

- Still dispatch all 5 advisors in parallel. Independence still matters.
- The Contrarian's verdict gets **double weight** in synthesis.
- The Expansionist is muted: they still return their analysis, but the Chairman explicitly does not lead with upside. Upside goes in a footnote unless it directly defuses a Contrarian flaw.
- The Chairman's recommendation must explicitly answer: *what is the kill criterion?* Under what conditions would the user abandon this?
- If 2+ advisors flag the same flaw, the default recommendation is **fix the flaw or kill the idea**, not "proceed with awareness."

## Synthesis structure (overrides default)

```markdown
# Pressure Test — <slug>

**Question:** <one paragraph>

## What will kill this
<lead with the worst flaw. 2-3 sentences. Quote the Contrarian directly if their phrasing is sharp.>

## Other ways it dies
<remaining flaws, ranked. Each gets 1-2 sentences.>

## What survives the pressure test
<only the parts of the original idea that genuinely held up under scrutiny. Be honest if it's "not much.">

## Kill criterion
<the specific signal that means "abandon this." A date, a metric, a milestone. Be concrete.>

## If you must proceed
<the smallest, most-reversible version of the bet. The thing you can try without committing.>

## The recommendation
<one sentence. Often: "fix flaw X by date Y or stop."

---

## The five voices (verbatim)
[same as default]
```

## When NOT to use pressure-test

- When the user has already decided not to do the thing and just wants validation. Pressure-testing a graveyard is cruel.
- When the question is genuinely about upside discovery (use default `/council` or lean Expansionist).
- When the user is in a fragile emotional state about the decision. The Contrarian doesn't soften, and a pressure-test on an already-bruised ego is unhelpful, not useful.
